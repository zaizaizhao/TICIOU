Ticiou 与 SkillHub 同步工作流设计

这份文档整理 Ticiou 如何与 SkillHub 协作：SkillHub 负责 skill 的发布、权限、版本和下载；Ticiou 负责 profile 装配、同步策略、交互提示和本地 agent 配置渲染。

核心结论

ticiou use -u zhaoyanan 不应该默认安装 zhaoyanan 上传的全部 skills。更稳妥的语义是： 激活 zhaoyanan 这个 Ticiou profile，并按照 profile 中明确保存的 selection 和 lock 安装、恢复和渲染。

推荐默认：已启用 skill 可以提示或自动更新；新增 skill 只提示，不默认加入；删除或不可访问的 skill 默认保留本地缓存并提示用户处理。

职责边界

SkillHub

  • 存储和分发 skill 包。
  • 管理 namespace，例如 global 和 emrois。
  • 管理 PUBLIC、NAMESPACE_ONLY、PRIVATE 可见性。
  • 提供搜索、解析版本、fingerprint 和下载接口。
  • 用 token 判断当前用户能访问哪些 skills。

Ticiou

  • 管理 profile，例如 zhaoyanan。
  • 保存 profile 选择的 SkillHub skills。
  • 安装、更新、禁用或保留本地 skill 缓存。
  • 渲染 Claude / Copilot 的 hooks、agents、commands、prompts。
  • 维护 manifest 和 lock，保证可重复执行。

推荐的 namespace 模型

Namespace 定位 推荐内容 典型可见性
global 组织级公共仓库 通用代码审查、TDD、诊断、文档编辑等基础能力 PUBLIC
emrois 团队级仓库 emrois 团队专用流程、平台规范、发布检查 NAMESPACE_ONLY
emrois + owner self 个人维护的团队内能力 zhaoyanan 自己维护、但只想在团队内或个人 profile 中启用的 skills NAMESPACE_ONLY 或 PRIVATE

Ticiou profile 可以组合这些来源，但组合方式应通过 selector、label 或明确 selection 表达，而不是直接按权限全量加载。

Profile 与身份

ticiou use -u zhaoyanan 中的 zhaoyanan 是 Ticiou profile 名，不等于认证身份。 真正的访问权限由 SkillHub token 决定。

推荐 token 来源顺序：

  1. --token 参数，仅当前命令使用。
  2. SKILLHUB_TOKEN 环境变量。
  3. Ticiou 自己的本机凭据，例如 ~/.ticiou/skillhub-credentials.json。
  4. 交互式粘贴 token，可选择仅本次使用或保存到本机。
  5. 后续扩展系统 keychain。

Ticiou 不需要集成 skillhub CLI 二进制。它可以在内部维护 src/skillhub/ 模块，包含 HTTP client、凭据解析、registry 归一化、zip 下载与安装逻辑。

如果 token 对应用户不是 zhaoyanan，Ticiou 应提示：

Profile: zhaoyanan
SkillHub identity: another-user

Private skills owned by zhaoyanan may not be accessible with this token.
Continue with accessible skills only? [y/N]

Token 注入和凭据管理

token 只在运行时注入 SkillHub HTTP 请求，不写入项目配置、profile、manifest 或 lock。推荐使用用户级凭据文件： 

~/.ticiou/skillhub-credentials.json

示例格式：

{
  "tokens": {
    "http://localhost:3000": {
      "token": "sk_xxx",
      "savedAt": "2026-06-15T00:00:00.000Z",
      "lastVerifiedUser": "zhaoyanan"
    }
  }
}

解析顺序：

1. --token
2. SKILLHUB_TOKEN
3. ~/.ticiou/skillhub-credentials.json
4. 交互式粘贴 token
5. anonymous

新增凭据命令：

ticiou skillhub login --registry http://localhost:3000
ticiou skillhub whoami --registry http://localhost:3000
ticiou skillhub logout --registry http://localhost:3000

登录交互：

$ ticiou skillhub login --registry http://localhost:3000

SkillHub registry [http://localhost:3000]:
Paste SkillHub token: ********
Verify token now? [Y/n]
Save token locally? [Y/n]

Logged in as zhaoyanan
Saved token for http://localhost:3000

--token 适合临时调试，但不建议长期使用，因为可能进入 shell history 或进程列表。 交互式粘贴 token 时必须隐藏回显。

当 use 或 sync 找不到 token 时，交互式命令可以提示：

SkillHub token not found for http://localhost:3000.

Options:
  1. Paste token for this run
  2. Paste and save locally
  3. Continue anonymously
  4. Cancel
Choose [1]:

非交互环境不能要求用户粘贴 token。没有 token 时，只能匿名访问 PUBLIC skills，或在 profile 依赖受限 skills 时失败。

命令体系

命令 用途 是否修改本地
ticiou skillhub login 粘贴并保存 SkillHub token 到用户本机 只修改用户级凭据
ticiou skillhub whoami 验证当前 token 对应的 SkillHub 身份 否
ticiou use -u zhaoyanan 激活 profile，按 lock 恢复和渲染配置 是
ticiou skill list --remote 查看当前 token 可访问的远端 skills 否
ticiou skill add emrois/api-review 把 skill 加入当前 profile selection 是
ticiou skill remove emrois/api-review 从当前 profile 移除或禁用 skill 是
ticiou skill sync 同步已启用 skills，处理更新、新增、删除 按交互结果
ticiou skill sync --frozen 只检查，不修改；适合 CI 或稳定环境 否

首次使用流程

1. 身份检查 读取 registry 和 token，调用 SkillHub whoami，确认当前远端身份。
2. 发现候选 按 namespace、owner、label 查出可访问 skills，例如 global baseline 和 emrois active。
3. 用户选择 让用户勾选要启用的 skills，不默认加载全部。
4. 安装和锁定 resolve、download、安装到 agent skills 目录，写入 lock 和 manifest。 
$ ticiou use -u zhaoyanan

后续 use 行为

后续执行 ticiou use -u zhaoyanan 时，Ticiou 读取已保存的 selection 和 lock。默认只保证本地状态恢复，不主动吸收远端新增 skills。

同步策略

A. 自动检查

每次 Ticiou 启动时可以后台检查 remote metadata。检查应尽量轻量，优先使用 ETag / Last-Modified；在 SkillHub 未实现条件请求前，可以使用 resolve 返回的 fingerprint。

自动检查不等于自动安装。默认只产生 pending 状态和提示。

B. 手动同步

# 同步所有已启用 skills
ticiou skill sync

# 同步特定 namespace
ticiou skill sync --namespace emrois

# 查看可用但未加载 skills
ticiou skill list --remote

C. 智能提示

检测结果 默认行为 可配置行为
已启用 skill 修改 提示更新；配置 auto_refresh 时静默更新 prompt / auto / frozen
新增 skill 提示是否加载，不默认加入 prompt / ignore / auto-add
远端删除 提示是否保留本地缓存，默认保留 keep-cache / disable / remove
权限变更导致不可访问 保留缓存并提示 token 或权限问题 重新登录、disable 或 remove

配置示例

profiles:
  zhaoyanan:
    skillhub:
      registry: http://localhost:3000
      auto_refresh: false
      background_check: true
      update_policy: prompt
      new_skill_policy: prompt
      deleted_skill_policy: keep-cache
      selectors:
        - namespace: global
          label: baseline
          policy: auto
        - namespace: emrois
          label: team-shared
          policy: auto
        - namespace: emrois
          owner: self
          label: active
          policy: prompt-new
      selections:
        - namespace: global
          slug: code-review
          version: ^1.0.0
        - namespace: emrois
          slug: api-review
          version: latest

Lock 文件

Ticiou 应维护 .ticiou/.runtime/skillhub-lock.json，记录已安装 skill 的具体版本和 fingerprint。 这让 use 能稳定恢复，也让 sync 能判断更新。 

{
  "version": 1,
  "profile": "zhaoyanan",
  "registry": "http://localhost:3000",
  "skills": [
    {
      "namespace": "emrois",
      "slug": "api-review",
      "version": "1.2.0",
      "fingerprint": "sha256:abc123",
      "visibility": "NAMESPACE_ONLY",
      "status": "installed",
      "installTargets": [
        {
          "agent": "codex",
          "path": ".codex/skills/api-review"
        }
      ]
    }
  ]
}

SkillHub API 交互逻辑

Ticiou 不应长期 shell 调 npx @astron-team/skillhub install 作为核心实现。更适合直接复用 SkillHub API 或抽出的共享 client。

阶段 SkillHub 接口 Ticiou 使用方式
身份确认 GET /api/cli/v1/auth/whoami 确认 token 对应用户，决定 private skill 是否可能访问
发现候选 GET /api/v1/me/skills 或 GET /api/web/skills?ownerId=... 列出可选 skills；后续建议新增 CLI discovery API
解析版本 GET /api/cli/v1/skills/{namespace}/{slug}/resolve 拿到 version、versionId、fingerprint
下载内容 GET /api/cli/v1/skills/{namespace}/{slug}/versions/{version}/download 下载 zip，解压到目标 agent skills 目录
差量检查 ETag / Last-Modified 或 fingerprint 避免重复下载未变化的 skill

权限说明

Skill 可见性 匿名 namespace 成员 owner namespace admin/owner
PUBLIC 可安装 可安装 可安装 可安装
NAMESPACE_ONLY 不可安装 可安装 可安装 可安装
PRIVATE 不可安装 不可安装 可安装 可安装
token 是认证凭据，不应写入 .ticiou/config.yaml、profile、manifest 或 lock。终端日志也不应输出 token。

推荐默认值

配置项 默认值 理由
background_check true 给用户及时反馈，但不阻塞 use
auto_refresh false 避免不经确认改变 agent 上下文
update_policy prompt 已启用 skill 的更新需要用户知道
new_skill_policy prompt 新增 skill 不能默认进入 profile
deleted_skill_policy keep-cache 避免误删 private 或临时不可访问 skill 的本地副本

最终方案

Ticiou 继续存在，但定位收敛为 SkillHub skills 的 profile orchestrator。SkillHub 管 skill 的权威来源和权限； Ticiou 管当前项目、当前 profile 到 agent 配置的装配。

ticiou use -u zhaoyanan 只激活并恢复已选择的 profile。远端新增 skill 通过 ticiou skill list --remote 和 ticiou skill sync 提示和选择。已启用 skill 可在 auto_refresh 打开后静默更新，否则手动确认。
