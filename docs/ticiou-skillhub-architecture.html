Ticiou 与 SkillHub 交互及架构说明

本页说明 Ticiou 如何把 profile selection、SkillHub discovery/resolve/download API、lock/cache 和平台渲染串成一个闭环。它是对本轮集成代码的结构化说明。

核心数据流

1 CLI 命令 ticiou skill add、ticiou use、ticiou skill sync
2 配置与凭据 .ticiou/config.yaml + ~/.ticiou/skillhub-credentials.json
3 SkillHub API discover / resolve / download / whoami
4 lock/cache skillhub-lock.json + zip 解压缓存
5 平台渲染 .claude/skills/skillhub-* 或 Copilot 输出目录

新增 SkillHub 接口

接口：GET /api/cli/v1/skills/discover

这个接口是本轮对应 Ticiou 远端列表能力的主要 SkillHub 改动。

层级 代码位置 职责
Controller CliSkillController.discover 绑定 query params，校验 owner=self、visibility、size，返回统一 API response。
App Service CliSkillAppService.discover 调用搜索服务，补充 owner、fingerprint、labels，组装 CLI response。
Search App SkillSearchAppService.search 把 namespace、labels、ownerId、visibility 和权限范围转成 search query。
Search Adapter PostgresFullTextQueryService.search 把过滤条件下推到 SQL，同时保证 count query 参数一致。
Auth RouteSecurityPolicyRegistry 允许匿名 GET；允许 API token GET；匿名只能看到 PUBLIC。
OpenAPI web/src/api/generated/schema.d.ts 生成 operations["discover"] 和 CliDiscoverResponse 类型。

配置文件

.ticiou/config.yaml 只保存 registry、策略和 selections，不保存 token。

profiles:
  users:
    kaibin.xu:
      skillhub:
        registry: http://localhost:3000
        selections:
          - namespace: emrois
            slug: api-review
            policy: auto

凭据文件

token 只保存在用户目录，按 normalized registry 作为 key。

~/.ticiou/skillhub-credentials.json

非 Windows 系统写入后会设置 0600；Windows 跳过 chmod，避免平台异常。

普通同步流程

读取 .ticiou/config.yaml 中当前 profile 的 SkillHub selections。
解析 token：flag → env → 本机 store → prompt → anonymous。
对 explicit selection 调用 SkillHub resolve，得到 version、versionId、fingerprint。
cache 缺失或需要刷新时下载 zip，并安全解压到 runtime cache。
写入 skillhub-lock.json，记录 profile、registry、fingerprint、installTargets。
把 cache 转成 managed files，由 manifest 统一写入平台目录并清理 stale files。

--frozen 检查流程

读取 config 和现有 lock。
调用 resolve 检查远端版本和 fingerprint。
如果 lock 缺失、cache 缺失或远端有更新，只输出提示。
不写 lock。
不下载 zip。
不渲染新文件，适合 CI 或稳定环境检查。

SkillHub discovery 请求内部路径

Ticiou
skill list --remote → listSkills → resolveToken → SkillHubClient.discover → HTTP GET
SkillHub Controller
CliSkillController.discover 解析 q/namespace/owner/ownerId/label/visibility/page/size， 处理 owner=self 和 size 上限。
SkillHub Service
CliSkillAppService.discover 调 SkillSearchAppService.search， 再补充 owner、labels、fingerprint。
Search
SearchQuery 携带 visibility scope、namespace、ownerId、visibility、labels。 PostgresFullTextQueryService 把过滤条件写入 SQL。
Response
返回 ApiResponse<CliDiscoverResponse>，Ticiou 格式化为 namespace/slug@version VISIBILITY - summary。

安全边界

  • token 不写入项目 config、lock、manifest 或测试快照。
  • 跨域 download redirect 不携带 Authorization header。
  • zip 解压拒绝绝对路径和逃逸路径。
  • lock 校验 profile 和 registry，避免错误复用。
  • SkillHub discovery 允许匿名访问，但 visibility scope 限制匿名只能看到公开技能。

跨平台边界

  • 路径安全判断使用 resolve、relative、isAbsolute。
  • 输出 manifest 使用相对路径和 POSIX 风格资源路径。
  • Windows 跳过 chmod，macOS/Linux 设置凭据文件权限。
  • SkillHub registry URL 会去掉 query、hash 和尾部斜杠，避免不同命令解析不一致。

端到端示例

ticiou skillhub login --registry http://localhost:3000 --token sk_xxx
ticiou skill list --remote --namespace emrois --owner self --label active
ticiou skill add emrois/api-review
ticiou use -u kaibin.xu
ticiou skill sync --frozen
login 保存本机 token list 调 discovery add 写 selection 并触发 use use 同步 lock/cache 并渲染 frozen 只检查不写入
实现范围说明： 当前闭环已覆盖 explicit skill 的 add、resolve、download、cache、lock 和 render。selector 结构已进入配置模型，但自动展开 selector 为 explicit skills 是后续增强点。
